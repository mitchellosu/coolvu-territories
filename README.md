# CoolVu North Texas Territory Map

Front-desk tool: type a caller's ZIP, street address, or city to see which CoolVu franchisee owns it.

- Territory ZIP lists: CoolVu corporate territory PDF dated 7.28.26
- ZIP boundaries: US Census 2020 ZCTAs
- Basemaps: Esri Light Gray Canvas, OpenStreetMap
- Address search: OpenStreetMap Nominatim
